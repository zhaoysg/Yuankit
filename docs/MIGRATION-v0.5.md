# v0.5 迁移说明

## 资产预设

schemaVersion 保持 1。parsePreset 接受 libraryVersion 0.2.0、0.3.0、0.4.0、0.5.0，逐字段校验并统一返回 0.5.0。不会执行任意 CSS、HTML、脚本，也不会静默接受未知字段或未来版本。旧来源文件不修改；重新导出 JSON 时产生新版本配置。不要替换成 `latest`。

v0.1 只含主题参数的 JSON 与此格式不同，需要用 ConfigProvider 读取或手动映射；不是可自动迁移的资产预设。浏览器中损坏的缓存不会被静默覆盖。命名方案保存仍依赖浏览器 localStorage 的可用性，建议导出文件备份。

## 组件注册与类型

v0.4 部分后增组件没有进入根 .d.ts 与全局注册清单。本版从 registry/components.json 生成全局注册器，纳入 55 个基础/AI/配置组件，并补齐根类型导出。建议显式导入；blocks/templates 不自动全局注册。

不等于完成全部 Props 的端到端类型检查。旧组件的一些类型仍宽泛，Vue SFC 与 vue-tsc 消费端矩阵留待后续验证。

## 行为修复

Combobox 外部值同步、禁用、方向键跳过禁用项、活动选项 ARIA、Esc 关闭；Popover 外部点击按当前实例判断，避免多个浮层相互污染，Escape 返回触发器焦点。动效重播先捕获 DOM 元素，不在延时回调读取已失效的 event.currentTarget。

Toast 新组件暂停时间时同时考虑键盘焦点与鼠标，不会在焦点仍停留时因为鼠标移出而关闭。

## AI 资产使用

YkAsset 的 AI 页面是明确标记的本地演示。生产项目使用 YkAIChatPage / YkAIAssistantDock 或 12 个 AI primitive，传入业务数据；工作台的假回复与假模型不是后台能力。保存的 JSON 包含样式与演示内容，不包含会话数据库或模型状态。

## 超宽屏布局

旧文档样式在 ≥1700px 时会把主体左右居中，而 Studio 重置了内边距但没有隐藏原侧栏，导致资产目录被文档侧栏遮挡，点击跳到无关组件。本版让 Studio 独立使用自己的资产导航，文档目录在工作台默认隐藏，通过顶部工作区导航仍可访问；手机可打开目录。回归使用真实可点击性检查，不再用 force click 绕过遮挡。
