# 文章与灵感来源接入规范

## 本轮证据范围

已核对用户两张截图所列 11 个站点的首页/入口并整理分类，记录在 `references/inspiration-sources.json`。不是完整文章研读、整站抓取、视频帧提取或每个案例实测。本轮区块和效果是自有实现，不是搬运网站内的品牌设计与素材。

| 来源 | 进入哪层 |
| --- | --- |
| Navbar Gallery、SupaHero、CTA Gallery、Footer Design、404s | 区块/页面布局参考 |
| 60fps、Design Spells | 动效/微交互参考，需补充键盘与 reduced-motion 行为 |
| IF Catalogue | 与数据使用、透明度和用户控制相关的交互规则 |
| ABTest Design | 实验案例参考，不能将别人转化结果当成自己项目的保证 |
| UXSnaps | 体验拆解、检查点与交互说明 |
| UI Playbook | 组件用法、状态与可用性规范 |

## 每收到一篇文章

建立 `references/articles/<slug>.md`，根据实际内容记录，不凭标题猜测：标题、URL/附件、阅读范围、发布时间/访问日期、关键设计目标、可复用结构、可参数化外观、交互/键盘/性能/响应式、与已有资产重叠、许可依据、实施决定与剩余问题。

随后给出判定：已有组件新增 preset / 新能力 / 新区块或模板 / 仅规则文档 / 暂缓。

来源展示并不自动授予截图、图标、字体、视频和商业源码再发布许可。默认只借鉴抽象设计规则并独立实现；确需改编开源代码时核对具体文件及版本许可证，保留要求的归属和声明。授权不清素材不进入发布包。

## 验收

能在预览交互 → 参数调整真实生效 → 导出配置可重现 → 组件行为不退化 → 许可证和来源可追溯 → 文档明确支持/不支持。验收后再登记为 beta。


## v0.3 归档判断

文章中的内容先判断属于：基础组件、页面区块、页面模板、动效方案、设计规范。导航/首屏/CTA/页脚优先进入页面区块；404/403/500 等完整状态进入页面模板；可脱离具体组件复用的运动规律进入动效方案。只有真正需要新行为契约时才新增基础组件。
