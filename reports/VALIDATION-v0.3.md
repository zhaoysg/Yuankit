## 本轮重点

1. 工作台调整为左侧资产库 / 中间真实 Vue 画布 / 右侧属性检查器。
2. 属性按内容、尺寸与布局、字体、外观、行为、动效六类管理。
3. 顶部增加项目级品牌色、圆角、密度快速主题控制。
4. 新增字体、行高、字间距、字重、边框样式、透明度、背景模糊、密度、缓动、延迟、缩放、动效强度等字段。
5. 新增独立公告栏、落地页组合，以及 fade / slide / scale / glow / shimmer / pulse 六类动效方案。
6. 页面区块继续与基础组件共享同一套 Token 和配置体系，没有拆成第二个仓库。
